## 1. 기능 요구사항 (Functional Requirements)

### 1.1 반려동물 프로필 관리

| ID | 구분 | 요구사항 | 우선순위 | 인수 기준 |
|----|------|----------|----------|-----------|
| REQ-001 | 프로필 등록 | 보호자는 반려동물의 이름, 종(강아지/고양이), 품종, 생년월일, 성별, 중성화 여부를 등록할 수 있어야 한다 | Must | 필수 항목(이름, 종) 입력 후 저장 성공 / 저장된 프로필이 홈 화면에 정상 노출됨 |
| REQ-002 | 프로필 사진 업로드 | 보호자는 반려동물 프로필 사진을 업로드할 수 있어야 한다 | Must | JPG/PNG 파일 업로드 후 썸네일로 표시됨 / 미업로드 시 기본 이미지로 대체됨 |
| REQ-003 | 프로필 수정·삭제 | 보호자는 등록된 프로필 정보를 수정하거나 삭제할 수 있어야 한다 | Must | 수정 후 변경 사항이 즉시 반영됨 / 삭제 시 해당 반려동물의 모든 기록이 함께 삭제됨 (삭제 확인 모달 필수) |

### 1.2 데일리 체중 기록

| ID | 구분 | 요구사항 | 우선순위 | 인수 기준 |
|----|------|----------|----------|-----------|

| REQ-005 | 체중 추이 차트 | 최근 30일 체중 추이 차트가 홈 화면에 노출되어야 하며, 기간 필터(7일/30일/90일) 조회가 가능해야 한다 | Must | 기록 저장 즉시 차트에 반영됨 / 기록이 1건 이상인 경우 차트 표시 / 필터 변경 시 해당 기간 데이터 즉시 재렌더링 |
| REQ-006 | 전일 대비 변화량 표시 | 전일 대비 체중 변화량과 방향(▲/▼)을 기록 화면 및 홈에 표시해야 한다 | Must | 전일 기록이 있는 경우 변화량(소수점 1자리)과 방향 표시 / 전일 기록 없으면 표시 생략 |
| REQ-007 | 권장 체중 범위 표시 | 품종·나이 기반 권장 체중 범위를 기록 화면에 표시해야 한다 | Must | 프로필에 종·품종·생년월일이 등록된 경우 권장 범위가 표시됨 / 미등록 시 표시 생략 |

## 3. 우선순위 매트릭스 (MoSCoW)

| 우선순위 | 요구사항 ID | 비율 |
|----------|-------------|------|
| **Must** (필수, MVP 필수 조건) | REQ-001, REQ-002, REQ-003, REQ-004, REQ-005, REQ-006, REQ-007, REQ-008, REQ-009, REQ-010, REQ-011, REQ-012, REQ-013, REQ-014, REQ-019, REQ-020, REQ-021, REQ-022, REQ-023 | 약 83% |

| **Could** (선택, v1.1 이후) | 다두 펫 지원, 동물병원 직접 연동, 커머스 연동 | — |
| **Won't** (이번 버전 제외) | 식사량·배변 추가 기록, 수의사 계정(B2B), 커뮤니티·소셜 기능 | — |

> Must 기능이 하나라도 미완성이면 Go/No-Go 판단에서 No-Go.
> Should 기능은 M4(2026-07-17) 기준 일정 여유가 있을 때 포함.
