## 2. 공통 규칙

### 2.1 공통 레이아웃

```
+-------------------------------+  375px
| [상단 앱바 — 화면별 상이]        |  44px
+-------------------------------+
|                               |
|  [콘텐츠 영역]                  |  가변
|                               |
+-------------------------------+
| [하단 탭바 — 인증 화면에서만 표시]|  56px
| 홈  |  기록  |  리포트  |  MY  |설정|
+-------------------------------+
```

### 2.2 공통 컴포넌트

| 컴포넌트 | 설명 | 사용 화면 |
|----------|------|-----------|
| 토스트 알림 | 하단 중앙, 3초 자동 소멸 | 저장 완료, 오류 발생 시 |
| 로딩 스피너 | 전체 화면 반투명 오버레이 | API 호출 중 |
| 오프라인 배너 | 화면 상단 Teal 색상 배너, "오프라인 모드" 표시 | 네트워크 미연결 시 홈·기록 화면 |
| 빈 상태 UI | 일러스트 + 안내 문구 + 행동 유도 버튼 | 데이터 0건 시 |
| 스켈레톤 | 카드/리스트 형태 플레이스홀더 | 데이터 로딩 중 |

### 2.3 상태 정의 (공통)

| 상태 | 표시 방식 |
|------|-----------|
| 로딩 | 스켈레톤 UI 또는 전체 로딩 스피너 |
| 빈 상태 | 중앙 정렬 아이콘 + 안내 문구 + 행동 유도 버튼 |
| 에러 | 오류 토스트 + 재시도 버튼 (해당 섹션 내) |
| 오프라인 | 상단 오프라인 배너 + 기능 제한 안내 |

```

|  +-------------------------+  |
|                               |
|  체중 입력 *                   |

|  |         4.8          kg |  |  <- 소수점 1자리, 숫자 패드
|  +-------------------------+  |
|                               |

|                               |
|      체중 변화 확인             |
|                               |
|  입력하신 체중이 전일(4.9kg)     |
|  대비 많이 차이납니다.           |
|  4.8 kg으로 기록할까요?         |
|                               |
|       [취소]      [확인]       |
|                               |
```

**UI 컴포넌트**

| 컴포넌트 | 타입 | 설명 | 인터랙션 |

| 기록 완료 버튼 | Button (primary, Teal, 전폭) | 저장 실행 | 범위 초과 시 오류 메시지 / ±15% 초과 시 확인 모달 |
| 재확인 모달 | Modal (confirm) | 큰 변화 시 재확인 | 확인 탭 시 저장 / 취소 탭 시 입력 화면 유지 |
