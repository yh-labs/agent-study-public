## 1. Executive Summary

### 1.1 한 줄 요약

반려동물의 체중·음수량을 1분 안에 기록하고, 월간 리포트로 이상 징후를 조기에 발견하는 보호자 전용 건강 트래킹 웹앱

### 1.2 핵심 지표

| 항목            | 내용                                                                      |
| --------------- | ------------------------------------------------------------------------- |
| 서비스명 (가칭) | 펫로그 (PetLog) — 브랜드명 확정 전 임시 명칭                             |
| 목표 시장       | 국내 반려동물 헬스케어 앱 시장 (2025년 약 10조 원 이상 추정)              |
| 타겟 사용자     | 강아지·고양이를 키우는 20~40대 보호자 (1차), 노령견·노령묘 보호자 (2차) |
| 핵심 가치       | 1분 기록 → 이상 징후 조기 감지 → 의료비 절감                            |
| 수익 모델       | 프리미엄 구독 (기본 기록 무료 + 월간 리포트·심층 분석 유료)              |
| 개발 기간       | 9주 (2026-05-19 ~ 2026-07-22)                                             |

## 2. 서비스 배경 및 시장 기회

### 2.1 시장 현황

국내 반려동물 시장은 2022년 이미 8.5조 원을 달성하였으며, 연평균 10% 성장세를 이어가 2025년 현재 약 10조 원 이상으로 추정되고, 2032년에는 21조 원에 달할 것으로 예측된다. 반려동물 양육 인구는 1,546만 명(전체 인구의 약 30%)으로, 보호자의 86.4%가 건강 관리에 높은 관심을 보이고 있다. 특히 최근 2년간 평균 반려동물 치료비가 102.7만 원으로 전년 대비 약 2배 급증하면서, 예방적 관리를 통한 의료비 절감 수요가 실질적으로 형성되어 있다.

| 항목                         | 수치                                       | 출처          |
| ---------------------------- | ------------------------------------------ | ------------- |
| 국내 반려동물 시장           | 약 10조 원 이상 (2025년 추정)              | 마켓리서치 #3 |
| 국내 시장 성장률             | 연평균 약 10%                              | 마켓리서치 #3 |
| 글로벌 반려동물 케어 앱 시장 | 약 32~35억 달러 (2025년) / CAGR 7.7~18%   | 마켓리서치 #2 |
| 국내 반려인 수               | 1,546만 명 (전체 인구의 약 30%)            | 마켓리서치 #4 |
| 최근 2년간 평균 치료비       | 102.7만 원 (전년 대비 약 2배 증가)         | 마켓리서치 #4 |
| 건강 관리 관심도             | 보호자의 86.4%가 반려동물 건강 관리에 관심 | 마켓리서치 #4 |

### 2.2 시장 기회

- **기회 1: 국내 일상 기록 앱 공백** — 체중·음수량에 특화된 국내 앱이 사실상 존재하지 않음. 유일한 경쟁 서비스였던 펫츄가 서비스를 중단하여 시장 공백이 더욱 확대된 상황 — 근거: 마켓리서치 #6
- **기회 2: 의료비 급등으로 예방 케어 수요 형성** — 최근 2년간 평균 치료비가 102.7만 원으로 2배 급증하면서, 이상 징후 조기 감지로 병원 방문 빈도를 줄이려는 보호자 수요가 실질적으로 형성됨 — 근거: 마켓리서치 #4, #8
- **기회 3: 대기업(SKT) B2C 진입 지연** — SKT 에이닷펫(A.PET)의 B2C 펫 플랫폼 출시가 2026년 초 무기한 연기됨에 따라 B2C 일상 기록 앱 시장의 직접 경쟁 위협이 단기적으로 완화됨 — 근거: 마켓리서치 #8 (팩트체크 업데이트)
- **기회 4: 노령 반려동물 세그먼트의 높은 지불 의사** — 전체 반려동물의 40%가 7세 이상 노령으로, 의료비가 일반 대비 2.3배 높고 유료 구독 전환율도 가장 높을 것으로 예상 — 근거: 마켓리서치 #11

## 4. 서비스 전략

### 4.1 핵심 가치 제안 (Value Proposition)

> "반려동물의 체중·음수량을 1분 안에 기록하고, 이상 징후를 즉시 감지하며, 월간 리포트를 수의사에게 바로 공유할 수 있는 가장 빠른 반려동물 건강 트래킹 서비스"

보호자가 기존에 느끼는 3가지 핵심 불만을 직접 해결한다.

| 기존 불만               | 해결 방식                                                          |
| ----------------------- | ------------------------------------------------------------------ |
| 기록 마찰 (복잡한 입력) | '열기 → 숫자/증감 버튼 입력 → 저장' 3단계, 1분 이내 완료 UX                |
| 이상 징후 인지 지연     | 최근 7일 평균 대비 체중 10% 이상 감소 시 알림, 오타 방지용 재확인 컨펌 제공 |
| 수의사 공유 불편        | 30일 건강 이력 월간 리포트 자동 생성 + PDF 1탭 공유                |

착수보고서 In Scope를 기준으로 정의한다. Should 기능은 일정 상황에 따라 v1.1로 이관 가능하다.

| 구분      | 기능                         | 우선순위 | 설명                                                                                                      |
| --------- | ---------------------------- | -------- | --------------------------------------------------------------------------------------------------------- |
| MVP       | 반려동물 프로필 등록         | Must     | 이름, 종(강아지/고양이), 품종, 생년월일, 성별, 중성화 여부, 사진 업로드                                   |
| MVP       | 데일리 체중 기록             | Must     | kg (소수점 1자리), 최근 30일 추이 차트 홈 노출 및 필터(7일/30일/90일) 지원, 전일 대비 변화량 표시, 품종·나이 기반 권장 체중 범위 표시 |
| MVP       | 데일리 음수량 기록           | Must     | ml 단위 및 10ml 단위 증감(+/-) 버튼 지원, 물그릇 용량 설정으로 잔여량 역산 지원, 체중 기반 권장 음수량 범위 표시                           |

| MVP       | 회원가입·로그인             | Must     | 소셜 로그인 (카카오·구글 우선 / 애플은 v1.1 검토)                                                        |

### 4.3 차별화 전략

1. **'1분 기록' UX 최적화**: 기존 앱의 복잡한 온보딩·다단계 입력을 제거하고, 체중·음수량을 한 화면에서 동시 입력(숫자 및 10ml 단위 증감 버튼 활용) 가능하도록 설계. 첫 기록 직후 즉시 30일 추이 차트(7일/30일/90일 필터)가 시각화되어 즉각적 피드백 제공 → 7일 리텐션 확보의 핵심 (근거: 마켓리서치 #7, #10)
2. **의료적 신뢰성 기반의 이상 징후 알림**: 최근 7일 평균 대비 체중 10% 이상 감소 등 임계값을 수의학적 근거에 기반하여 설정하고 오타 방지 팝업을 제공. 알림에 권장 조치(동물병원 방문 권고)를 명기하여 단순 트래킹을 넘는 신뢰 가치 제공 (근거: 마켓리서치 #11)
3. **월간 리포트 PDF — 수의사-보호자 커뮤니케이션 도구**: 동물병원 방문 시 즉시 제시 가능한 포맷의 30일 건강 이력 리포트. 데이터 기반 수의사 상담을 가능하게 하여 B2C를 넘는 가치 창출. 노령견·노령묘 보호자의 높은 지불 의사 세그먼트에 직접 소구 (근거: 마켓리서치 #11)
