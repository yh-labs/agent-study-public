## 1. 개요

### 1.1 테스트 범위

본 문서는 반려동물 건강 기록 웹앱(PWA)의 v1.0 릴리스 전 품질 검증을 위한 테스트 시나리오를 정의합니다.

| 항목 | 내용 |
|------|------|
| 테스트 대상 버전 | v1.0 (MVP) |
| 포함 범위 | F-001~F-007 전 기능, 비기능 요구사항(NFR-001~013) |
| 제외 범위 | v1.1 이후 예정 기능 (다두 펫, 동물병원 연동, 커머스 연동) |
| 테스트 기준 문서 | 요구사항정의서 v1.0, 기능명세서 v1.0 |

### 1.2 테스트 유형

| 유형 | 설명 | 대상 |
|------|------|------|
| 기능 테스트 | 각 기능의 정상 흐름(Happy Path) 및 예외 처리 검증 | F-001~F-007 |
| 경계값 테스트 | 입력값 범위 경계 조건 검증 | F-002, F-003 |
| 비기능 테스트 | 성능, 보안, 오프라인 동작 검증 | NFR-001~013 |
| 회귀 테스트 | 주요 기능 정상 동작 최종 확인 | 핵심 P0 케이스 |

### 1.3 합격 기준

| 우선순위 | 합격 기준 |
|----------|-----------|
| P0 (Critical) | 100% 통과 필수 — 1건 이상 실패 시 Go/No-Go = No-Go |
| P1 (High) | 95% 이상 통과 |
| P2 (Medium) | 90% 이상 통과 |
| P3 (Low) | 80% 이상 통과 |
