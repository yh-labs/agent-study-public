## 1. 개요

### 1.1 목적

본 문서는 펫로그(PetLog) 반려동물 건강 기록 웹앱의 일관된 시각적 경험을 보장하기 위한 디자인 시스템을 정의합니다. 개발자, 디자이너, 기획자가 동일한 기준으로 UI를 구현하고 유지보수할 수 있도록 컬러, 타이포그래피, 스페이싱, 컴포넌트, 아이콘, 모션 등 전반적인 디자인 표준을 기술합니다.

### 1.2 디자인 원칙

| 번호 | 원칙 | 설명 |
|------|------|------|
| 1 | 간결함 (Simple) | 반려동물 체중·음수량 기록이라는 핵심 행동을 1분 이내에 완료할 수 있도록 불필요한 시각 요소를 제거하고 명확한 정보 계층을 유지한다. |
| 2 | 신뢰감 (Trustworthy) | 의료·건강 데이터를 다루는 서비스로서 정확한 수치와 명확한 상태 표시를 통해 보호자가 안심하고 데이터를 신뢰할 수 있는 시각 언어를 사용한다. |
| 3 | 친근함 (Warm) | 반려동물과 보호자의 감성적 유대를 반영하여 차갑지 않고 따뜻한 톤을 유지한다. 반려동물 관련 맥락에서는 부드러운 곡선과 편안한 컬러 팔레트를 활용한다. |

## 3. 타이포그래피

### 3.1 폰트 패밀리

| 역할 | 폰트 | 적용 범위 | 로드 방식 |
|------|------|-----------|-----------|
| 한글 | Pretendard | 한글 문자 전체, 한글 혼재 텍스트 | CDN (jsDelivr) 또는 로컬 폰트 파일 |
| 영문/숫자 | Inter | 영문, 숫자, 단위(kg, ml, %), 날짜 | Google Fonts CDN |

**CSS font-family 선언 순서**:

```css
font-family: 'Inter', 'Pretendard', -apple-system, BlinkMacSystemFont, sans-serif;
```

> Inter를 먼저 선언하여 숫자·영문에 Inter가 적용되고, 한글에는 Pretendard가 fallback으로 적용됩니다.

## 4. 스페이싱 & 레이아웃

### 4.1 4px 기반 그리드 시스템

모든 간격과 크기는 4px의 배수를 기준으로 합니다. 이를 통해 시각적 리듬의 일관성을 확보하고 Tailwind CSS의 기본 스페이싱 스케일과 완전히 호환됩니다.

### 4.2 간격 토큰

| 토큰명 | 값 | Tailwind 클래스 | 주요 사용 사례 |
|--------|----|----------------|---------------|
| space-1 | 4px | `p-1`, `m-1`, `gap-1` | 아이콘과 텍스트 사이 최소 간격 |
| space-2 | 8px | `p-2`, `m-2`, `gap-2` | 버튼 내부 아이콘-텍스트 간격, 인라인 요소 간격 |
| space-3 | 12px | `p-3`, `m-3`, `gap-3` | 소형 카드 내부 패딩, 인접 항목 간격 |
| space-4 | 16px | `p-4`, `m-4`, `gap-4` | 카드 내부 표준 패딩, 컨테이너 좌우 패딩 |
| space-5 | 20px | `p-5`, `m-5`, `gap-5` | 섹션 내 항목 간 수직 간격 |
| space-6 | 24px | `p-6`, `m-6`, `gap-6` | 카드 간 수직 간격, 섹션 상단 패딩 |
| space-8 | 32px | `p-8`, `m-8`, `gap-8` | 주요 섹션 간 구분 간격 |
| space-10 | 40px | `p-10`, `m-10`, `gap-10` | 화면 상하단 여백, 온보딩 단계 간격 |
| space-12 | 48px | `p-12`, `m-12`, `gap-12` | 대형 섹션 분리, CTA 버튼 상단 여백 |

## 5. 컴포넌트 스타일

### 5.1 Button

버튼 공통 규격: 높이 48px, 폰트 Body-L(16px) SemiBold, 둥근 모서리 `rounded-xl` (12px), 최소 너비 44px, 전폭(full-width)이 기본.

| 변형 | 배경색 | 텍스트색 | 테두리 | 높이 | Tailwind 클래스 요약 | 사용 화면 |
|------|--------|--------|--------|------|---------------------|-----------|
| primary | `#028090` (brand-primary) | `#FFFFFF` (text-inverse) | 없음 | 48px | `bg-[#028090] text-white h-12 rounded-xl font-semibold` | 기록 완료, 시작하기, 저장하기, 공유하기 |
| secondary | `#FFFFFF` (surface-card) | `#028090` (brand-primary) | `1px solid #028090` | 48px | `bg-white text-[#028090] border border-[#028090] h-12 rounded-xl font-semibold` | PDF 저장, 취소 (모달 내) |
| danger | `#DC2626` (semantic-error) | `#FFFFFF` (text-inverse) | 없음 | 48px | `bg-[#DC2626] text-white h-12 rounded-xl font-semibold` | 프로필 삭제 확인 (MOD-001) |
| ghost | `transparent` | `#028090` (brand-primary) | 없음 | 48px | `bg-transparent text-[#028090] h-12 rounded-xl font-semibold` | 텍스트 형태 보조 액션 |

**버튼 상태별 스타일**:

| 상태 | 처리 방식 |
|------|-----------|
| Hover (웹) | `hover:opacity-90` |
| Active (탭) | `active:scale-[0.97]`, `transition-transform duration-100` |
| Disabled | 배경 `#CBD5E1`, 텍스트 `#FFFFFF`, `cursor-not-allowed`, `opacity-60` |
| Loading | 배경 유지, 텍스트 대신 스피너(16px) 표시 |

**소셜 로그인 버튼 (SCR-001 전용)**:

| 구글로 시작하기 | `#FFFFFF` | `#1E293B` | `border border-[#E2E8F0]` 추가 |

### 5.5 Switch (토글)

설정 화면(SCR-010) 알림 ON/OFF에 사용.

## 7. 모션 & 애니메이션

### 7.1 트랜지션 기본값

| 토큰 | Duration | Easing | 적용 대상 |
|------|----------|--------|-----------|
| transition-fast | 100ms | `ease-in-out` | 버튼 active 스케일, 색상 전환 |
| transition-base | 150ms | `ease-in-out` | SegmentedControl 탭 전환, Input focus |
| transition-smooth | 200ms | `ease-out` | Toast 퇴장, Switch 전환, 모달 페이드 |
| transition-enter | 300ms | `ease-out` | BottomSheet 진입, 모달 진입 |

### 7.2 주요 인터랙션 모션

| 인터랙션 | 애니메이션 | Duration | Easing |
|----------|-----------|----------|--------|
| 버튼 탭 | `scale: 0.97` (active 상태) | 100ms | ease-in-out |
| BottomSheet 열림 | `translateY(100%) -> translateY(0)` | 300ms | ease-out |
| BottomSheet 닫힘 | `translateY(0) -> translateY(100%)` | 200ms | ease-in |
| Modal 열림 | `opacity: 0, scale: 0.95 -> 1` | 200ms | ease-out |
| Modal 닫힘 | `opacity: 1 -> 0` | 150ms | ease-in |
| Toast 진입 | `translateY(100%) -> translateY(0)` | 200ms | ease-out |
| Toast 퇴장 | `opacity: 1 -> 0` | 150ms | ease-in |
| SegmentedControl 탭 | 배경 슬라이드 이동 | 150ms | ease-in-out |
| 체중 차트 렌더링 | 라인 드로우 애니메이션 | 600ms | ease-out |
| 스켈레톤 로딩 | 좌에서 우로 shimmer | 1500ms | linear, loop |
| 오프라인 배너 표시 | `translateY(-100%) -> 0` | 250ms | ease-out |

### 7.3 모션 원칙

- 기능적 모션만 사용합니다. 사용자의 행동에 맥락적으로 연결된 모션만 허용하며 장식용 애니메이션은 제거합니다.
- `prefers-reduced-motion: reduce` 미디어 쿼리를 감지하여 모션을 최소화하거나 제거합니다.
- 연속 기록 인터랙션(체중 입력 → 저장)에서는 전환 시간을 짧게 유지하여 기록 속도를 방해하지 않습니다.

## 8. 접근성 가이드

### 8.1 색상 명도 대비

WCAG 2.1 AA 기준 본문 텍스트 4.5:1, 대형 텍스트(18px Bold 이상) 3:1을 충족합니다.

| 조합 | 전경 | 배경 | 대비율 | 기준 충족 |
|------|------|------|--------|-----------|
| 주요 본문 텍스트 | `#1E293B` | `#F8FAFC` | 약 14.5:1 | AA / AAA |
| 보조 텍스트 | `#64748B` | `#FFFFFF` | 약 5.9:1 | AA |
| Primary 버튼 텍스트 | `#FFFFFF` | `#028090` | 약 4.7:1 | AA |
| Accent 배경 위 텍스트 | `#FFFFFF` | `#02C39A` | 약 2.8:1 | 대형 텍스트 AA |
| Caption 텍스트 | `#64748B` | `#FFFFFF` | 약 5.9:1 | AA |
| Error 텍스트 | `#DC2626` | `#FFFFFF` | 약 5.3:1 | AA |
| Disabled 텍스트 | `#CBD5E1` | `#FFFFFF` | 약 1.6:1 | 비활성(의도적) |

> Accent Mint(`#02C39A`)는 배경색으로 단독 사용 시 흰색 텍스트의 대비율이 낮으므로, 작은 텍스트 위에는 사용하지 않습니다. 아이콘 강조, 뱃지 등 보조 시각 요소에 한정합니다.

### 8.2 터치 타겟 크기

모든 인터랙티브 요소의 터치 영역은 최소 44px × 44px을 보장합니다.

| 컴포넌트 | 시각적 크기 | 터치 영역 확보 방식 |
|----------|------------|-------------------|
| 버튼 (전폭) | 48px 높이 | 높이 자체 충족 |
| BottomNavigation 탭 | 아이콘 24px + 텍스트 | 탭 영역 전체 분할 (약 75px) |
| Switch | 트랙 24px | 래퍼에 `min-h-[44px]` 적용 |
| 아이콘 버튼 (알림 등) | 24px | 패딩으로 44px 영역 확보 (`p-[10px]`) |
| 스텝퍼 증감 버튼 | 48px × 48px | 높이 자체 충족 |
| 뒤로가기 | 24px | 래퍼에 `w-11 h-11` 적용 |

### 8.3 ARIA 및 시맨틱 마크업

| 항목 | 적용 방법 |
|------|-----------|
| 아이콘 전용 버튼 | `aria-label="버튼 목적"` 필수 |
| 폼 입력 필드 | `<label>` 또는 `aria-label` 연결 |
| 오류 메시지 | `role="alert"` + `aria-live="polite"` |

### 8.4 포커스 관리

- 모달 및 바텀시트 열림 시 내부 첫 번째 포커스 가능 요소로 포커스를 이동합니다.
- 모달 닫힘 시 트리거 버튼으로 포커스를 복원합니다.
- 포커스 링: `outline: 2px solid #028090`, `outline-offset: 2px` (기본 outline 제거 후 커스텀 적용).
