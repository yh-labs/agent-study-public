## 3. 주요 성과

1. **코드 구현 WBS 예정일 대비 5일 선행 완료**: W3~W4(6월 8일~30일) 집중 구현으로 M3 마일스톤(구현 완료, WBS 예정 2026-07-05)을 2026-06-30에 달성.

2. **Supabase 풀스택 연동 완료**: 소셜 로그인(OAuth)부터 실데이터 저장·조회, 이미지 스토리지, 관리자 API(탈퇴 CASCADE 삭제)까지 전 기능을 Supabase 단일 백엔드로 연동 완료.

3. **Tech Stack 변경 대응**: 초기 계획(React + Vite + Express.js)에서 Next.js 16 App Router + Route Handlers로 전환하여 프론트엔드·백엔드를 단일 프로젝트로 통합. Vercel 서버리스 환경에 최적화.

4. **MVP 범위 조정 및 실행**: 오프라인 지원(PWA/IndexedDB), Web Push 알림, PDF 리포트를 v1.1로 이관하고 핵심 기능(로그인, 기록, 차트, 리포트, 설정)을 MVP 범위 내 완료. 설정 화면에 v1.1 예정 항목 명시.

5. **Vercel 프로덕션 배포 완료**: GitHub 연동 후 환경변수(Supabase URL/Key, Service Role Key, CRON_SECRET) 설정 완료. Supabase OAuth Redirect URL 등록 완료. 실기기(iPhone) 및 브라우저(Safari, Chrome) 동작 확인.

6. **실사용 데이터 검증 완료**: 온보딩 → 체중 기록 → 음수량 기록 → 차트 생성 → 리포트 조회 전 흐름을 실데이터로 2일간 연속 검증. 전일 대비 증감 표시, 라인 차트, 15% 초과 확인 모달 동작 확인.

7. **E2E 테스트 자동화 기반 구축**: Playwright WebKit(Safari 엔진) 기반 E2E 테스트를 도입. 로그인 화면 렌더링 및 OAuth 리디렉션 자동 검증 + 스크린샷 캡처.
