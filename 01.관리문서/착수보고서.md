**작성일**: 2026-05-26
**작성자**: PM

## 1. 프로젝트 개요

강아지·고양이 보호자가 반려동물의 **데일리 체중·음수량**을 간편하게 기록하고, **월간 건강 리포트**를 통해 장기적인 건강 추이를 확인할 수 있는 웹앱 서비스.

반려동물의 체중 변화 및 수분 섭취 이상은 질병의 초기 징후일 수 있으나, 대부분의 보호자는 이를 수기로 관리하거나 기록하지 않는 상황이다. 본 서비스는 이러한 문제를 해결하여, 보호자가 일상 속에서 반려동물의 건강 이상 신호를 조기에 인지하고 동물병원 방문 시 신뢰할 수 있는 건강 이력을 제공할 수 있도록 한다.

| 항목 | 내용 |
|------|------|
| 프로젝트명 | 반려동물 건강 기록 웹앱 |
| 플랫폼 | 최신 웹 브라우저 (Chrome 90+, Safari 14+, Firefox 90+, Edge 90+) / PWA 지원 |
| 기술 스택 | React + Vite / Express.js / PostgreSQL (Supabase) / Vercel |
| 총 기간 | 9주 (2026-05-19 ~ 2026-07-22) |
| 팀 규모 | PM 1, 기획자 1, 디자이너 1, 개발자 2 |

---

## 2. 프로젝트 목표

| 구분 | 목표 | 측정 지표 |
|------|------|-----------|
| 단기 | MVP 출시 (체중·음수량 기록 + 월간 리포트) | 앱스토어 정식 출시 완료 |
| 중기 | 런칭 후 3개월 내 활성 사용자 확보 | MAU 5,000 / 7일 리텐션 ≥ 40% |
| 중기 | 보호자의 일상적 건강 기록 습관 형성 | 데일리 기록 완료율 ≥ 60% |
| 장기 | 안정적인 구독 기반 수익 구조 확립 | 앱스토어 평점 ≥ 4.2 |

## 3. 프로젝트 범위

### 3.1 범위 내 (In Scope)

| # | 기능 | 우선순위 |
|---|------|----------|
| 1 | 반려동물 프로필 등록 (이름, 종, 품종, 생년월일, 성별, 중성화 여부, 사진) | Must |
| 2 | 데일리 체중 기록 (kg, 소수점 1자리, 7일 추이 차트, 권장 범위 표시) | Must |
| 3 | 데일리 음수량 기록 (ml, 물그릇 잔여량 역산, 권장 범위 표시) | Must |
| 4 | 월간 건강 리포트 자동 생성 (30일 추이 차트, PDF 내보내기) | Must |
| 5 | 기록 리마인더 푸시 알림 | Should |
| 6 | 이상 징후 감지 알림 (전일 대비 체중 10% 이상 변화) | Should |
| 7 | 회원가입·로그인 (소셜 로그인) | Must |
| 8 | 오프라인 기록 지원 및 자동 동기화 (PWA Service Worker) | Must |

### 3.2 범위 외 (Out of Scope)

| # | 항목 | 비고 |
|---|------|------|
| 1 | 다두 펫 지원 (멀티 반려동물) | MVP 이후 검토 |
| 2 | 동물병원 예약·공유 연동 | MVP 이후 검토 |
| 3 | 식사량·배변 등 추가 기록 항목 | MVP 이후 검토 |
| 4 | 수의사 계정(B2B) 기능 | 별도 기획 필요 |
| 5 | 커뮤니티·소셜 기능 | 범위 외 |
